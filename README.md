

## 🌟 项目简介

这是一个基于 **Python + Django + Vue3 + MySQL** 构建的网络课程在线学习平台。

### 🧩 功能模块一览

- **用户端**：登录注册 / 首页 / 课程信息 / 学习资源 / 社区信息 / 个人中心
- **管理端**：社区信息管理 / 新闻资讯管理 / 课程学习 / 课程信息 / 一级分类 / 二级分类管理 / 课程排行管理 / 资源类型管理 / 学习资源管理 / 用户管理 / 轮播图管理

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **Python**: 3.8  
- **Django**: 2.0  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2


⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: PyCharm / VS Code  
- **前端开发**: VS Code、HBuilder X  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
